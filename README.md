# Campus Equipment Borrowing Management System

## General Objective
To develop a web-based system that automates equipment borrowing, availability checking, and return tracking for students, faculty, and staff.

## Specific Objectives
1. Provide students and faculty with a searchable equipment catalog and real-time availability.
2. Enable staff to manage equipment, approve/reject requests, and record borrow/return transactions.
3. Ensure data integrity through input validation and role-based access.

## Tools and Technologies
- HTML, CSS, PHP, MySQL
- XAMPP, phpMyAdmin, VS Code
- Git, GitHub, ChatGPT/Claude

## Setup
1. Install XAMPP and start Apache & MySQL.
2. Import `sql/campus_equipment.sql` in phpMyAdmin.
3. Place project folder in `htdocs`.
4. Access `http://localhost/campus-equipment/`.
5. Login with:
   - Staff: staff@example.com / staff123
   - Student: student@example.com / student123
   - Faculty: faculty@example.com / faculty123
